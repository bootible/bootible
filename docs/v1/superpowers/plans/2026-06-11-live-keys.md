# v1.1 Live Keys Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every config key bootible documents is live (read by a module), every docs page tells the truth, and four researched Group-B features ship: HDR toggle, refresh rate, HidHide, directory scaffolding — plus EmuDeck prereq pre-install and a HAGS drift probe.

**Architecture:** Same pipeline as v1.0 (docs/superpowers/plans/2026-06-10-windows-first-hour.md): pure logic in `config/rog-ally/lib/*.ps1` (Linux-testable), thin modules, schema keys in Run.ps1's `Validate-ConfigSchema`, defaults in `config/rog-ally/config.yml`. New systemic guard: a SchemaLiveness test that fails CI when a config key has no consumer.

**Tech Stack:** PowerShell 5.1-compatible, Pester 5.6.1 (`~/bin/pwsh -NoProfile -c 'Invoke-Pester -Path ./tests/'` from worktree root, currently 92/0), PSScriptAnalyzer Error-clean on touched files.

**Decisions baked in (Gavin, 2026-06-11):** keep EmuDeck-only (research: no automation path exists; settings.json pre-seed is unsupported/fragile); delete `disable_cortana` (Cortana removed in Win11 24H2), `install_reshade` (per-game injection — global key has no meaning), the 11 per-emulator keys, `user_home`; do NOT implement `compact_os`; rename `install_hidmanager` → `install_hidhide`; SSH key-management restore is a SEPARATE future spec, not this branch — the 6 `ssh_*` keys are deleted here with a "planned feature, will return with new names" note in the parity table.

**House rules (identical to v1.0 plan):** verify-gate stamp (`touch .claude/.verified ../.claude/.verified` in the SAME call as a passing test run; commit in a SEPARATE call); commit messages never contain "claude"/"anthropic", no Co-Authored-By; `git add` only listed files; TDD with watched-fail-first for all pure logic.
