Your Ally

Set up your Ally

Pick how to apply your setup.

Restore the factory image first (ASUS Cloud Recovery)
  1. Enter the BIOS: tap F12 at the ROG logo (or Settings → Recovery → Advanced startup → UEFI firmware settings).
  2. Check the BIOS clock is correct — a wrong time blocks Cloud Recovery.
  3. Press Y (or F7 → Advanced) → ASUS Cloud Recovery.
  4. Connect Wi-Fi, agree; when asked to back up your files → Cancel (fresh machine), then OK to reset.

Full steps also ship in README-restore.txt inside your kit.
